DBC HGU-V210-4AC Access Control Architecture:

DBC FTTH ONT routers support MAC Filtering under Security / Advanced Network -> MAC Filter. To prevent accidental network lockout, Net Sentinel enforces:

  • Strict protection against blocking the Gateway (192.168.1.1) or Host Laptop.
  • Explicit confirmation showing MAC, IP, and device name before applying any rule.
  • Complete audit logging of all submitted, confirmed, or rejected operations.
